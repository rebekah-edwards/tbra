# Brand / icon source assets

- `app-icon-master-2048.png` — 2048² master for the app icon (gradient asterisk
  on charcoal, full square, opaque). Regenerate the favicon + PWA icons from this:
  Space Grotesk "*" with linear gradient `#a3e635 → #38bdf8 → #c084fc`, ink width
  ~60% of the tile, centered. The icon set (favicon.ico, public/icons/*) was cut
  from this via a Chrome-canvas pipeline (playwright-core, channel:chrome).
- Favicon uses a larger asterisk (~74% ink) for legibility at 16–32px.
